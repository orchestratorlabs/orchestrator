### Probe 8 — settles D1

Did they read PASS as being about **the component** or **the evaluation**?

```
☐ the component ("my button is fine")
☐ the evaluation ("the check was right")
☐ unclear / didn't distinguish
```

> If "the component" dominates, the verdict is functionally about the component
> whatever the prompt intends — and the two vocabularies should be **merged**,
> not renamed. That reverses D1 as currently written.
